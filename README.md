# ①課題名
バカラアプリ

## ②課題内容（どんな作品か）
- 基本的なルールはカードゲームのバカラにならっている
- 3回戦行い、最終チップ数が15枚を超えていたら勝ちというゲーム
- 各ゲームが始まる前に賭ける枚数を選択する

## ③アプリのデプロイURL
https://masahikoaoyagi.github.io/1107_GitHub_02_kadai/

## ④工夫した点・こだわった点
- 勝敗をバカラの手ではなく、チップの枚数に変更した
- 賭け数は「タップするたびに1枚ずつ増え、持っているチップを超えたら1枚に戻る」仕組みにした
（逆に、コインで視覚的にわかりやすいようにする方法がわからなかった…）
- `canFlip`（カードをめくってよいか）と `isGameFinish`（ゲームが終わったか）という true / false の変数を用意し、勝負の途中やゲーム終了後には賭け数を変えられないようにした

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 難しかったのは、JSで条件分岐を考えること。手元で条件分岐について図示しながら進めた
- 負けてチップが減ったとき、賭け数が持っているチップより多いまま残ってしまう問題。`if (bet > chip)` で賭け数を持っている枚数に合わせる処理を追加して解決した
- ゲームの終わり方が「3回戦が終わったとき」と「チップが0枚になったとき」の2通りあること。`||`（または）を使って1つの if にまとめた

- 次回トライしたいことは以下
- 3枚目へもつれ込む展開
- 罫線の再現
